# 0010: Converting, ripping and scanning as jobs

Accepted, 25 November 2026.

Long work runs on a pool of all the cores but one while the music plays, each job a list of items, shown in the message line with a Stop. Conversion writes beside the target and moves it into place, so a stopped job leaves nothing half made. Ripping is converting the CD's AIFF files with tags from MusicBrainz (looked up by disc ID, editable before ripping).
