# 0005: Title formatting as foobar2000's

Accepted, 25 November 2026.

foobar2000's syntax is what people who'd want this player already know, and their patterns work here: %fields%, [optional sections], 'quoted text', and $functions. Fields fall back as foobar's do (%artist% to the album artist). It's used for playlist columns, Now Playing, renaming and moving, the converter's names, sorting and facets. formatPath keeps a pattern's / as folders while a / inside a value (AC/DC) becomes _.
