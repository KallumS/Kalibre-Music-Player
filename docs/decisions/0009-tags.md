# 0009: Tags through TagLib, named as foobar2000 names them

Accepted, 25 November 2026.

TagLib reads and writes every format's tags with one PropertyMap. The player names fields as foobar2000 does ("album artist", "totaltracks") whatever the format calls them, and keeps "3/12" track numbers as a number and a total. Several values are kept as several. Covers are read from the file, or cover/folder/front images beside it.
