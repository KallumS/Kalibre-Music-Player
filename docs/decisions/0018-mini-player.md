# 0018: The mini player is the same window, made small

Accepted, 25 November 2026.

The musician asked for a mini player that takes as little of the screen as
possible. It's the main window itself, not a second one: the panels, menu
bar and message line are hidden, and the window loses its title bar and
shrinks to a 440 x 68 point strip (scaled with the text size) holding the
cover, the title and artist, the seek bar and time, and Previous,
Play/Pause and Next. Being the same window, every keyboard shortcut and the
Mac's menus still work, and there's never a second window to lose. It stays
in front of other windows unless turned off (right-click). It's dragged by
its ground, and remembers where it was; going back restores the full
window exactly as it was. The command was added at the end of the command
list, as saved shortcuts name commands by number.
