# 0011: A layout tree the user edits

Accepted, 25 November 2026.

The window is a tree of rows, columns and tabs of named panels, kept as JSON. Edit Layout overlays every panel with a Change menu: replace it, add one beside it (left, right, above, below), add one as a tab, remove it. Dividers drag; a fixed-height part (the transport) keeps its height. Five presets to start from. Panels are made fresh when the layout changes; what they show is kept in settings, not in them.
