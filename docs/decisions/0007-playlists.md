# 0007: Playlists as tabs; autoplaylists

Accepted, 25 November 2026.

Several playlists as tabs, one shown, one playing; each a list of locations, so the same file can be in many. An autoplaylist holds what a query finds and follows the library. Orders: default, repeat playlist, repeat track, shuffle tracks (each heard once before any again, and Previous goes back through it), shuffle albums, random. A queue (Play Next) goes before the order.
